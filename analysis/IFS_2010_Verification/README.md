# IFS 2010 verification — supporting methods

Source scripts preserved for audits of IFS initialization, raw NPY vs NetCDF provenance, and full-year verification. These scripts are auxiliary checks rather than final figure generators. They may contain machine-specific input defaults and require the raw IFS/ERA5 assets locally; review configured paths before executing.

- `audit_ifs_initialization_2010.py`
- `verify_ifs_npy_nc_provenance.py`
- `verify_ifs_full_year_2010_WSL.py`

**Do not upload** the large ERA5/IFS input data, provisional CSVs, or forecast NetCDF files to GitHub.
