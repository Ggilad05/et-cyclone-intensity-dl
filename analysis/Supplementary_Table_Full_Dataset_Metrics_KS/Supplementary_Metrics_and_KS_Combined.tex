\caption{Performance metrics and pairwise comparisons of absolute forecast-error distributions over the full ERA5 dataset (1979--2020) for 6--24~h forecasts. In the performance section, MAE, Bias, and STD are evaluated on all available samples for each model; Bias is prediction minus observed cyclone-center mean sea-level pressure. Parentheses give 95\% confidence intervals (normal approximation for Bias). The Skill Score (SS) is defined as $1-\mathrm{RMSE}_{\mathrm{model}}/\mathrm{RMSE}_{\mathrm{Persistence}}$ and is calculated on common complete-case steps shared by Control, Leakage, and Linear Regression, with the same Persistence reference; its 95\% confidence intervals use cyclone-cluster bootstrap resampling. Simple NN SS uses its 6~h samples matched to Control persistence. Hence, the SS values need not be reconstructible from model-specific Bias and STD values. The column-header $N$ is the maximum available sample count for each lead time, not necessarily the count for every model or statistic. In the pairwise section, each entry is the percentage of matched steps in which the first model has smaller absolute error, followed by the two-sample KS distance $D$ (winning ratio / $D$). Pairwise comparisons are made on pair-specific matched forecast steps; only models evaluated at all four lead times are included. The original KS results report nominal $p<0.05$ for every comparison (without adjustment for temporal dependence within cyclones). Dashes indicate unavailable or unreported configurations.}
