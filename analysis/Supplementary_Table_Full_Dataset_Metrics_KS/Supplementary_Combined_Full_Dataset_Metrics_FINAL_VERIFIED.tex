Skill Score (SS) is defined as $1-\mathrm{RMSE}_{\mathrm{model}}/\mathrm{RMSE}_{\mathrm{Persistence}}$. For Simple NN, SS is evaluated on its own 6~h forecast steps matched to the Control persistence reference. Parentheses around SS indicate 95\% cyclone-cluster bootstrap confidence intervals. Column-header $N$ indicates the maximum available sample count per lead time, not necessarily the sample size used for every metric. Dashes denote configurations not evaluated or not reported.}
